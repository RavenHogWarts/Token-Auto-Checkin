## 2. 分层职责

| 层 | 职责 | 是否依赖 chrome API |
| --- | --- | --- |
| `domain/` | 纯类型 + 纯函数（Profile、结果、preset、解析） | 否（纯逻辑，易测） |
| `page/` | 注入页面执行的函数（DOM 操作） | 运行在页面，不用 chrome.* |
| `strategies/` | 认证与签到策略实现，组合 services + page | 是 |
| `core/` | 编排与流水线，调度 strategies | 是 |
| `services/` | storage / alarms / cookies / auth cache 封装 | 是 |
| `entrypoints/` | 入口与 UI | 是 |

关键原则：**`domain/` 与 `page/` 保持纯净、可单测**；chrome API 的副作用集中在 `services/` 与 `strategies/`。

## 3. 策略接口契约

```ts
interface AuthContext {
  headers?: Record<string, string>; // 认证头（可含 _tabId/_needsTabExecution 语义）
  tabId?: number;                    // 已打开的登录态标签页
  cookieOnly?: boolean;              // 仅靠 cookie，无显式头
  securityCheck?: boolean;           // 命中人机验证
}

interface AuthStrategyImpl {
  name: AuthStrategy;
  resolve(profile: SiteProfile, ctx: RunContext): Promise<AuthContext | null>;
}

interface CheckinStrategyImpl {
  name: CheckinStrategy;
  run(profile: SiteProfile, auth: AuthContext, ctx: RunContext): Promise<CheckinResult>;
}
```

`RunContext` 贯穿一次签到：`{ tabSession, cancelToken, logger }`。

流水线主干（`core/pipeline.ts`）伪代码：

```ts
async function runSite(profile, ctx) {
  const auth = await authRegistry.get(profile.auth.strategy).resolve(profile, ctx);
  if (auth?.securityCheck) return needsHuman(profile);

  let result = await checkinRegistry.get(profile.checkin.strategy).run(profile, auth, ctx);

  // 接口失败的兜底升级：api 失败 → page-click；401/CF → relogin 后重试
  result = await applyFallbacks(profile, auth, result, ctx);

  if (profile.checkin.api?.queryUrl && isSuccess(result))
    result.queryVerified = await verify(profile, auth);

  result.balance ??= await resolveBalance(profile, auth, ctx);
  return result;
}
```

「兜底升级」策略表（可配置，默认沿用参考实现行为）：

| 触发 | 默认兜底 |
| --- | --- |
| `api` 返回「需页面操作」文案 | → `page-click` |
| `api` 返回 401 | → `force-relogin` 重试一次 |
| `api` 返回 Cloudflare 403/HTML | → 清缓存 + 标签页内执行重试 |
| `page-click` 未找到按钮但检测到验证码 | → 结果 `needs-human`，按开关前置窗口 |

## 4. 数据流与存储键

`services/storage.ts` 统一管理，键规划：

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `siteProfiles` | `SiteProfile[]` | 站点档案（新版主数据） |
| `checkInResults` | `Record<siteId, CheckinResult>` | 最近一轮结果 |
| `authHeadersCache` | `Record<siteId, {headers, cachedAt}>` | 认证缓存，7 天过期 |
| `runState` | `CheckinRunState` | 进度、取消态 |
| `settings` | `{ autoSignTime, focusHumanVerificationWindow, ... }` | 全局设置 |
| `lastCheckInTime` | `string` | 上次签到时间 |
| `legacyBackup` | 旧 `userSites` | 迁移前备份 |

## 5. 消息协议（popup ↔ background）

类型化 union，避免裸字符串 action：

```ts
type Message =
  | { type: 'checkin/manual' }
  | { type: 'checkin/retry-site'; siteId: string }
  | { type: 'checkin/cancel' }
  | { type: 'status/get' }
  | { type: 'settings/update-auto-sign-time'; time: string }
  | { type: 'site/activate-manual-tab'; siteId: string } // needs-human 场景
  | { type: 'event/human-verification-detected' };        // 页面 → background
```

## 7. 权限（沿用，最小必要）

`cookies`（含 relogin 登出需清 cookie）、`storage`、`alarms`、`scripting`、`tabs`、`windows`、`webRequest`，`host_permissions: https://*/*`。relogin 策略需要 `chrome.cookies.remove` 清站点 cookie，权限已覆盖。
